# CPSP cCRE annotation pipeline

Pipeline for the functional annotation of GWAS loci for chronic post-surgical
pain (CPSP), applied to 45 independent loci. It covers LD-based independence
checks, ENCODE4 (V4) candidate cis-regulatory element (cCRE) annotation with a
matched genomic background, LD-proxy regulatory overlap, CTCF motif scanning,
and gene-level phenotype association (Open Targets) with a matched gene
background. Every step queries public resources and runs from the command
line. The locus table and the frozen background sets in `data/` are the only
inputs.

## Setup

Python 3.11 with the pinned packages, plus `tabix` (htslib) on the PATH for
Stages 1b and 8:

```bash
conda create -n cpsp-ccre python=3.11 -y
conda activate cpsp-ccre
pip install -r requirements.txt
conda install -c bioconda -c conda-forge htslib -y     # or: apt install tabix (Debian/Ubuntu), brew install htslib (macOS)
```

NumPy must stay below 2; the pinned pandas, SciPy and matplotlib builds predate
NumPy 2. Stages 5, 10 and 11 run offline. The others need internet access
(Ensembl REST, EBI FTP for 1000 Genomes, SCREEN downloads, JASPAR, Open Targets).

## Inputs

See `data/README.md`. The locus table `data/table1_final.csv` and the frozen
background lists are included. All results are generated by the stages below
and are git-ignored.

## Stages

| Stage | Script | Purpose | Writes (in `data/`) |
|---|---|---|---|
| 1 | `01_ld_resolution.py` | Pairwise LD through Ensembl REST (short range only) | `ld_resolution_results.json` |
| 1b | `01b_ld_longrange_direct.py` | r2 and D' from phased 1000 Genomes haplotypes at any distance, with a self-test against an Ensembl-reported value | `ld_longrange_results.json` |
| 2 | `02_ccre_annotation.py` | Nearest V4 cCRE within +/-50 kb for each locus; downloads the SCREEN BED files | `ccre_annotation_results.json` |
| 3 | `03_ctcf_motif_scan.py` | CTCF motif (JASPAR MA0139.1) scan of the sequence of each CTCF-bound cCRE | `ctcf_motif_results.json` |
| 4 | `04_phewas_query.py` | Full Open Targets association scan; Strong / Moderate / None tier per gene | `phewas_results*.json` |
| 5 | `05_background_tests.py` | Two-sided Fisher's exact tests against both backgrounds (Benjamini-Hochberg across the 8 cCRE classes) | printed |
| 6 | `06_generate_ccre_background.py` | Annotate the 500 background positions with the Stage 2 lookup | `background_ccre_n500_v4.json` |
| 7 | `07_nearest_gene.py` | Nearest protein-coding gene; `--table1` re-derives every assignment | `gene_assignment_check.csv` |
| 8 | `08_ld_proxy_annotation.py` | LD proxies (r2 >= 0.8, +/-500 kb) and direct cCRE overlap | `ld_proxy_results.json` |
| 9 | `09_generate_phewas_background_extension.py` | Draw further random protein-coding genes (seed 42) | `background_genes_extension_n200.txt` |
| 10 | `10_merge_phewas_background.py` | Concatenate the 300- and 200-gene PheWAS results | `phewas_background_n500.json` |
| 11 | `11_check_phewas_table1.py` | Compare Stage 4 tiers with the PheWAS column of the locus table | `phewas_table1_check.csv` |

Stages that call web services retry on transient errors and write results
incrementally.

## Running the pipeline

```bash
cd scripts
python 01b_ld_longrange_direct.py
python 02_ccre_annotation.py
python 03_ctcf_motif_scan.py
python 04_phewas_query.py --all
python 04_phewas_query.py --genes-file background_genes_n300.txt
python 04_phewas_query.py --genes-file background_genes_extension_n200.txt
python 10_merge_phewas_background.py
python 06_generate_ccre_background.py
python 07_nearest_gene.py --table1
python 08_ld_proxy_annotation.py --all
python 05_background_tests.py
python 11_check_phewas_table1.py
```

Stage 9 is not part of this sequence: it produced the frozen extension list.
Re-running it samples from the current Ensembl gene catalog and can give a
different draw.

## Notes

- **Reference panels:** each locus is matched to a 1000 Genomes panel by source
  study (`PANEL_BY_SOURCE` in `scripts/config.py`: CEU, EUR or GBR).
- **Fixed random sets:** the background positions and genes are frozen in `data/`.
- **External resources change:** the V4 registry (SCREEN downloads) and the
  current Open Targets release are external, so annotations and association
  ranks can shift between releases. Record the download date and release when
  you run the pipeline.
- **PheWAS classes:** Stage 4 assigns Strong, Moderate and None. Indirect is
  assigned by manual review of the returned associations.
- **Not reproduced here:** lead variants and p-values come from the published
  source GWAS. The UK Biobank LD estimate for MTF2/FNBP1L (r2 = 0.780) was
  computed with approved UK Biobank access, because UK Biobank genotypes are
  controlled-access and no public API returns LD from them. Pan-UK Biobank
  publishes precomputed LD matrices (https://pan.ukbb.broadinstitute.org/) for
  anyone who needs a UK Biobank-derived estimate.
